2. Im Startmenü alle drei Grafikdarstellungen anwählen; eine angefangene Antwort darf bei einem Bildstilwechsel nicht verloren gehen.
3. Figur/Name erstellen, Dokumente öffnen, Zuordnung, Reihenfolge, Mehrfachauswahl, Zahlenfelder, freie Begründung, Investmentauswahl bearbeiten und Navigation testen.
4. Vor dem Abschluss darf weder eine Musterlösung noch eine fachliche Punkteauswertung erscheinen. Allgemeine Hilfen/Formelsammlung sind erlaubt.
5. Spielstand als JSON exportieren; Browser schließen/neu öffnen; JSON importieren und zuletzt bearbeitete Aufgabe prüfen. Lokalen Autospeicher nach Browserneustart gesondert prüfen.
6. Nach 72 Schritten Abschluss bestätigen, 352 Maximalpunkte überprüfen, ausführliche Lösungseinblendung und Ausdruck/PDF testen.
7. Auf Unterrichtsgeräten zusätzlich 390px-/Touchansicht und Tastaturfokus testen; keine echten Mandanten- oder Teilnehmerdaten als Testfall eingeben.

Datei ist eine Lernsimulation – keine echte DATEV-Oberfläche und keine manipulationsgeschützte Klausur. Die Dauer 90–120 Minuten ist erst mit Testpersonen verifizierbar.
